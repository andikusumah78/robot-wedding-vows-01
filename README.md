One line of wedding vows for a robot couple, 158 characters — pure Python standard library, no dependencies.

> I promise to love you in sickness and in health, in Wi-Fi and in airplane mode, through each update and drained battery — until our final shutdown do us part.

## Run it

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt`.
